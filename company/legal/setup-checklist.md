# 法人設立チェックリスト

## 1. 形態の決定
- [ ] 合同会社（設立費用 約6〜10万円、決算公告不要）か株式会社（約20〜25万円、対外信用）かを決定
- [ ] 商号・本店所在地・事業目的・資本金・決算月を決定
  - 事業目的例: 「インターネットを利用したデジタルコンテンツの企画、制作及び販売」

## 2. 設立登記
- [ ] 法人実印の作成
- [ ] 定款作成（電子定款なら印紙代4万円不要）
- [ ] （株式会社のみ）定款認証
- [ ] 資本金の払込み
- [ ] 法務局へ登記申請 → 登記事項証明書の取得

## 3. 設立後の届出
- [ ] 税務署: 法人設立届出書 / 青色申告の承認申請書 / 給与支払事務所等の開設届出書 / 源泉所得税の納期の特例の承認申請書
- [ ] 都道府県税事務所・市区町村: 法人設立届
- [ ] 年金事務所: 健康保険・厚生年金保険 新規適用届（役員報酬を出す場合は加入義務）
- [ ] インボイス登録の要否を判断（`../tax/calendar.md` 参照）

## 4. 事業インフラ
- [ ] 法人口座開設
- [ ] 法人クレジットカード
- [ ] 会計ソフト契約
- [ ] note を法人アカウントで運用するか決定（振込先口座・特商法表記を法人名義に）
- [ ] 事業用メールアドレス・ドメイン

> 実際の手続き前に、最新の制度・費用を法務局・税務署・専門家で確認すること。
