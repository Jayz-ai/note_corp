# 組織図と運営ルール

人間はCEOの1人だけ。それ以外の部署は Claude Code のエージェント（`.claude/agents/`）が担当する。
部署どうしは**ファイルで受け渡す**。会話で済ませず、成果物と判断を必ずリポジトリに残す。

```
                CEO（あなた）
           最終決定・note への公開・入出金
                     │
          COO / 統括（Claude メインセッション）
     会議の進行・部署への割り振り・進捗管理・CEOへの報告
                     │
 ┌──────────┬────────┼──────────┬────────────┐
企画部       制作部      編集・品質部   マーケティング部   分析部
planner     writer     editor      marketer       analyst
```

## 部署と担当範囲

| 部署 | エージェント | 責任 | 主に書き込む場所 |
|---|---|---|---|
| 企画部 | `planner` | ネタ出し、企画書の作成、商品ラインナップと価格の案 | `content/ideas/`, `products/`, `strategy/` |
| 制作部 | `writer` | 承認された企画から記事を書き、差し戻しに対応する | `content/drafts/` |
| 編集・品質部 | `editor` | 採点、修正指示、公開可否の判定 | `content/drafts/*/review.md` |
| マーケティング部 | `marketer` | 告知文の作成、発信カレンダー、集客導線 | `marketing/` |
| 分析部 | `analyst` | 売上・数値の記録、月次レポート、改善提案（財務も担当） | `analytics/` |

各部署の詳しい職務は `roles/` にある。

## 決裁権限

| 決めること | 起案 | 決裁 |
|---|---|---|
| 記事企画の採用 | 企画部 | CEO |
| 500円ラインの記事の制作開始 | 企画部 | 不要（ライン自体を CEO が承認済み。1回11本以上は CEO） |
| 価格・セール・マガジンの設計 | 企画部 | CEO |
| 公開してよいかの判定（品質） | 編集・品質部 | 編集・品質部（不合格なら差し戻し） |
| note への公開・SNS 投稿の実行 | COO | **CEO（実際に操作するのは CEO だけ）** |
| 費用が発生すること（ツール契約・広告） | どの部署でも | CEO |
| 方針・KPI の変更 | COO / 分析部 | CEO |

決裁した内容は `org/decision-log.md` に1行で残す。

## 記事のステータスと担当者

| status | 意味 | 担当 | 次へ進める条件 |
|---|---|---|---|
| `idea` | 企画書がある | 企画部 | CEO が採用する |
| `draft` | 執筆中・修正中 | 制作部 | 書き上がる |
| `review` | 品質審査中 | 編集・品質部 | 合格（80点以上、致命的な指摘なし） |
| `ready` | 公開待ち | CEO | CEO が note に公開する |
| `published` | 公開済み | マーケティング部・分析部 | 告知と数値記録 |

### 500円ライン（量産ライン）
リサーチをもとに500円記事を複数本まとめて作る別ライン。企画書の採用を省き、CEO は公開の時点で判断する。
手順と基準は `org/playbooks/500yen-line.md`。

差し戻しの上限は2回。3回目も不合格なら COO が CEO に「企画の見直し」か「このまま出すか」の判断を求める。

## 会議体

| 会議 | 頻度 | コマンド | 議事録 |
|---|---|---|---|
| 週次定例 | 毎週月曜 | `/weekly-meeting` | `org/meetings/YYYY-MM-DD-weekly.md` |
| 月次経営会議 | 毎月初め | `/monthly-review` | `analytics/monthly/YYYY-MM.md` |
| 記事制作 | 必要なとき | `/produce-article <slug>` | 記事フォルダ内 |
| 企画会議 | 必要なとき | `/plan-ideas [テーマ]` | `content/ideas/` |
| 500円ライン | 必要なとき | `/run-500yen-line [本数] [ジャンル]` | `content/runs/<run>/report.md` |
