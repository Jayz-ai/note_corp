# 税務・労務カレンダー

決算月に合わせて書き換える（例: 3月決算）。

| 時期 | 内容 |
|---|---|
| 毎月10日 | 源泉所得税の納付（納期特例なら 7/10・1/20 の年2回） |
| 1月末 | 法定調書合計表・給与支払報告書・償却資産申告 |
| 決算月+2か月 | 法人税・消費税・地方税の申告納付 |
| 7月 | 社会保険 算定基礎届 |
| 中間 | 前年実績により予定納税 |
| 役員報酬 | 事業年度開始から3か月以内に改定・決定（定期同額給与） |

## 消費税・インボイス
- 設立1期目・2期目は資本金1,000万円未満なら原則免税（特定期間の要件に注意）
- note 購入者は主に個人のため、インボイス登録の必要性は低め。法人購入が増えたら再検討
