# 経理方針

## 基本ルール
- 証憑（領収書・請求書・note の売上明細）は `private/receipts/YYYY/MM/` に保存（電子帳簿保存法に沿う）
- 記帳は会計ソフトで月1回以上。リポジトリには **集計値だけ** を `analytics/sales-log.csv` に残す

## 勘定科目メモ
| 取引 | 勘定科目 |
|---|---|
| note 売上（手数料控除前） | 売上高 |
| note の販売手数料・決済手数料 | 支払手数料 |
| 有料素材・フォント・画像 | 仕入高 or 消耗品費 |
| 書籍・講座・他者の有料note（リサーチ目的） | 新聞図書費 / 研修費 |
| AI・SaaS 等のサブスク | 通信費 or 支払手数料 |
| 広告費（SNS広告等） | 広告宣伝費 |
| 外注（デザイン・校正） | 外注費 |
