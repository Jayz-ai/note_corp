# KPI 定義

| KPI | 定義 | 取得元 | 頻度 |
|---|---|---|---|
| 売上 | note 売上（手数料控除前） | note ダッシュボード | 月次 |
| 購入率 | 購入数 / 有料記事ビュー | note ダッシュボード | 記事ごと |
| 全体ビュー | 全記事のビュー合計 | note ダッシュボード | 週次 |
| スキ率 | スキ / ビュー | note ダッシュボード | 記事ごと |
| フォロワー増加数 | 月初比 | note / SNS | 月次 |
| 定期購読者数 | 月末時点 | note | 月次 |
| 制作時間 | 1記事あたり作業時間 | 自己記録 | 記事ごと |
