COO として500円ラインを1回まわしてください。手順と基準は `org/playbooks/500yen-line.md` に従います（最初に全文を読むこと）。

引数: $ARGUMENTS
- 1つ目が数字ならそれを本数にする（指定がなければ3本）。10本を超える指定は止めて、CEO に確認する
- 残りはジャンルの指定（なければジャンルを絞らない）

## 進め方
1. run 名を決め（今日の日付。`content/runs/<日付>/` が既にあれば `<日付>-2` のように番号を付ける）、フォルダを作る
2. planner エージェントに ① リサーチ・テーマ選定をさせる。テーマは本数＋2個出させる（予備）
3. テーマを確認する。採用基準を満たさないもの、直近30日と重複するものを外し、上から本数分を選ぶ
4. marketer エージェントに ② タイトルをさせる
5. writer エージェントに ③ 執筆をさせる。1本ずつ別のエージェントで並列に書かせてよい。渡すもの: テーマの全項目・採用タイトル・slug・run 名
6. editor エージェントに ④ 検品・審査をさせる。不合格は writer に差し戻す（最大2回）
7. 全記事に `scripts/check-article.py` を COO 自身でも実行し、判定が OK であることを確認する

## 最後に
`content/runs/<run>/report.md` に結果をまとめ、CEO にも同じ内容を結論から報告する:
- 読んだ件数と調べた先 / 選んだテーマと採用タイトル
- 記事ごとの字数（無料・全体）、点数、判定（ready / 差し戻し中）、パス
- 検出した禁止語の件数の合計
- うまくいかなかった工程（足りなかった件数などを実数で）
- CEO にお願いすること（公開する記事の選択、`【CEO確認】` への回答）

## 守ること
- note への投稿・公開はしない。成果物はリポジトリ内のファイルまで
- 架空の統計・体験談を書かせない
- 既存のファイルを消さない・上書きしない
